## APK Build Requirements
To create the APK file, you need:

### 1. Build Environment
- Python 3.x
- Buildozer installed (`pip install buildozer`)
- Android SDK/NDK (configured for Buildozer)
- Cython, Java JDK, and other Buildozer dependencies

### 2. Build Command
```bash
cd /path/to/project
buildozer android debug
```

### 3. Expected Output
The APK will be created at:
```
bin/BluetoothManager-0.1-debug.apk
```

## Deployment Instructions
Once the APK is built:

### 1. Copy to SD Card
```bash
# Copy to Documents folder
cp bin/BluetoothManager-0.1-debug.apk /sdcard/Documents/

# Or copy to Download folder
cp bin/BluetoothManager-0.1-debug.apk /sdcard/Download/
```

### 2. Install on Android Device
1. Navigate to the APK location using a file manager
2. Tap the APK file
3. Allow installation from unknown sources if prompted
4. Follow the installation wizard

### 3. App Permissions
The app requires these Android permissions:
- BLUETOOTH
- BLUETOOTH_ADMIN
- BLUETOOTH_SCAN
- BLUETOOTH_CONNECT
- ACCESS_FINE_LOCATION

## Troubleshooting
If buildozer fails:
1. Ensure Android SDK/NDK paths are correctly set in `~/.buildozer/android/platform/android-sdk`
2. Check that all dependencies are installed: `buildozer android clean`
3. Try building with verbose output: `buildozer -v android debug`
